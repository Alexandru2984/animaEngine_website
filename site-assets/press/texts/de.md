# animaEngine — Animierte Figuren, die auf Ihrem Desktop leben

Animierte Figuren, die auf Ihrem Desktop leben: Sie laufen, hüpfen, folgen einander, sagen etwas und erinnern Sie an Pausen. Linux und Windows. Kein Netzwerk, quelloffen.

Sie laufen, hüpfen, folgen einander und spielen Fangen über Ihren Fenstern — oder darunter. Tippen Sie eine an, und sie grüßt. Klicks gehen direkt an Ihre Arbeit durch.

## Was es kann

- **Jedes Bild wird lebendig** — Ziehen Sie ein PNG, GIF, WebP oder ein kurzes MP4 auf den Bildschirm oder fügen Sie ein Bild ein: Es wird zur Figur.
- **Ein eigenes Leben** — Laufen, umherstreifen, hüpfen, dem Mauszeiger oder einander folgen, Fangen spielen — oder ein kleines Skript, das Sie schreiben.
- **Durch Ihren Tag** — Erinnerungen an eine Pause oder ans Trinken, ein Fokus-Timer, Schlafenszeit und ein „Willkommen zurück“, wenn Sie wiederkommen.
- **Nie im Weg** — Klicks gehen hindurch. Bei Spielen und Filmen im Vollbild treten sie beiseite, und während Sie weg sind, halten sie still.
- **Szenen zum Teilen** — Speichern Sie, was auf dem Bildschirm ist, unter einem Namen, wechseln Sie je nach Tageszeit, und teilen Sie eine Szene oder eine Figur als eine Datei.
- **Leicht** — Kaum CPU, solange sich nichts bewegt, auf Wunsch dreißig Bilder pro Sekunde, und auf einem Linux-Laptop schläft die NVIDIA-GPU weiter.
- **Für alle** — Zehn Sprachen, Bildschirmleser, jede Aktion über die Tastatur, kontrastreiche Designs.
- **Privat von Grund auf** — Es baut überhaupt keine Netzwerkverbindung auf. Nichts über Sie oder Ihren Desktop verlässt Ihren Computer.
